Orbit - Gamified Adaptive SAT Platform

Live: orbit.bronzekite16385.chatgpt.site

Built as a tool for the students I tutor in mathematics in Covington, LA. I noticed Quizlet-style prep had zero retention, so I engineered Orbit with 500 skill-tagged questions, an ELO-based adaptive engine that targets weak skills, spaced-repetition Boss Fights, and a Socratic AI tutor with guardrails to prevent answer leaking.

Stack: Custom generation pipeline scripts/generate-bank.mjs -> bank.json, frontend game logic, localStorage progress, PWA + offline support, dark Orbit theme.

Impact: Deployed to tutoring students. Tracking sessions, accuracy improvement, and most common weak skill.
